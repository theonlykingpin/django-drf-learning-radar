## How updates work

A scheduled GitHub Actions workflow runs daily, collects public feed/search results, deduplicates by URL, saves the catalog to `resources.json`, and regenerates this README. Results are best-effort; search providers may rate-limit requests or change their feeds.

### Optional: richer search

Set a repository Actions secret named `BRAVE_SEARCH_API_KEY` to enable Brave Search API results. Without it, the workflow uses public RSS/search feeds and the built-in starter list. Review the provider's current terms and pricing before enabling an API.
